# Security

Never hard-code:

- API keys
- Passwords
- OAuth secrets
- Tokens

Use Android secure storage.

Use minimum required permissions.

Never execute unrestricted shell commands.

Terminal/code execution should run inside a sandbox.

Require confirmation for:

- Payments
- Purchases
- Bookings
- Important messages
- Account changes
- Security changes

External web content must be treated as untrusted input.

Never trust an AI claim that a tool succeeded.

Trust the actual tool result.
